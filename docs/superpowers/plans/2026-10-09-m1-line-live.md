# M1 Line Live Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The sweatshop line runs live: host-side witnesses behind an HTTP station API, bundle intake, andon pull/clear, `sweatshop line init|serve`, a scripted Andon watcher, a containerized Maker runner, and a harness scenario for break → andon → fix → clear.

**Architecture:** All trusted parts (witness keys, line remote, guard, evidence) live on the host in `sweatshop line serve`. Agents run in containers and reach the line only through an HTTP API on loopback, authenticated by a per-station bearer token that fixes role, agent ID and key. Candidates arrive as git bundles; the agent's repository is never read. The guard gains an andon state (`refs/line/andon` → event blob).

**Tech Stack:** Go (module `github.com/Fewbytes/sweatshop/line`, stdlib + existing go-toml only), git ≥ 2.45.1, docker-compatible engine (podman machine via `docker` CLI on dev), beads `bd` CLI, Claude Code CLI in the station image.

**Spec:** `design-docs/m1-line-live.md` (M1 design, binding), parent `design-docs/assembly-line-spec.md`, principles `design-docs/assembly-line-principles.md`.

## Global Constraints

- No new Go module dependencies. stdlib + `github.com/pelletier/go-toml/v2` only.
- All git calls from line code go through `gitx.Repo` (it strips `GIT_*` env, disables global/system config, uses `--end-of-options`). Never pass an agent-controlled string that may start with `-` without `rejectOptionInjection`.
- Witness git floor: `2.45.1` (already enforced by `Witness.checkGit`).
- Full commit IDs only (40 or 64 lowercase hex) across the API; reject anything else with HTTP 400.
- Station API listens on `127.0.0.1` only. Default port `7468`.
- Bundle upload cap: 256 MiB (`256 << 20` bytes).
- Fix trailer key: `Andon-Event`. Bead trailer key: `Bead`.
- Stop ref: `refs/line/andon` (existing `guard.StopRef`). Candidate prefix: `refs/line/candidates/` (existing).
- Files holding keys or tokens: mode `0600`; directories created for them `0700`.
- Every task ends with `just ci` green from the repo root, then one commit. Never push.
- Tools: use `rg`/`fd`, never grep/find. Scripts: python via `uv` if any are needed (none planned).
- Match surrounding code style: short doc comments explaining *why*, curried `ok(t)(...)` helper in tests that call git.

type AndonEvent struct {
	Commit       string    `json:"commit"`
	Check        string    `json:"check"`     // first failing required check
	ExitCode     int       `json:"exit_code"`
	EvidenceID   string    `json:"evidence_id,omitempty"`
	AgentID      string    `json:"agent_id"`
	Role         string    `json:"role"`
	KeyID        string    `json:"key_id"`
	Constitution string    `json:"constitution"`

func (g Guard) Pull(ctx context.Context, env attest.Envelope) (Result, error)
func (g Guard) Clear(ctx context.Context, env attest.Envelope) (Result, error)
func (g Guard) Stopped(ctx context.Context) (id string, event *AndonEvent, err error) // id "" when running

Semantics (from the M1 design, "Andon"):

- `verify(env)` (shared by Merge, Pull, Clear): trusted key → `untrusted_attestation`; key-role binding → `role_not_permitted`; commit subject present → else `untrusted_attestation`; constitution digest → `constitution_mismatch`; runner ID → `runner_mismatch`. Returns `(statement, keyID, attestedCommit)` or a reject. Move the existing code from `Merge` into it; Merge behaviour and order of reasons must not change.
- `Pull`: verify; `attestedCommit == current master` else `stale_evidence` (Result.Base = current master); the first attested check that is a required check (name **and** command match) with non-zero exit becomes `Check/ExitCode/EvidenceID`, none → `no_failure`. Build the event (PulledAt = `g.now()`; add `Now func() time.Time` to Guard, default `time.Now`), JSON-encode, `WriteBlob`, `UpdateRef(StopRef, blob, "")`. If the ref exists (before or via `ErrRefMoved`) → `already_stopped` with `Event` = current ID. Success → `Status: Stopped, Event: blob, Commit: attestedCommit`.
- `Clear`: `Stopped` → none → `not_stopped`; verify; commit == current master else `stale_evidence`; `checkResults(required, checks)` must pass (reuse; its `checks_missing`/`checks_failed` reasons apply); `DeleteRefIf(StopRef, id)`; `ErrRefMoved` → `not_stopped`. Success → `Status: Cleared, Event: id`.
- `Merge` while stopped: replace the `RefExists(StopRef)` block. If stopped, read `Trailer(commit, FixTrailer)`; if any value equals the event ID, continue with all remaining checks; else reject `line_stopped` with detail `"the andon cord is pulled (event <id>); fixes must carry the trailer Andon-Event: <id>"` and `Result.Event = id`.
- Role: any role may pull or clear (evidence counts, not identity), subject to the key-role binding.

Semantics:
- **Seeding** (both new paths, under `w.mu`): `cache.Git(ctx, "fetch", "--quiet", "--no-tags", "--force", "--prune", "--end-of-options", w.Upstream, "+refs/heads/*:refs/line/heads/*")`. `Upstream` empty → error `"witness has no upstream"`.
- **AttestBundle**: `commit` must be full hex (40/64) else error. Seed. `git bundle verify --quiet <bundle>` run in the cache (fails when prerequisites are missing: the bundle must be built against line master). Fetch: `git fetch --quiet --no-tags --force --end-of-options <bundle> +refs/sweatshop/*:refs/bundle/<nonce>/*` (the client's bundle carries exactly one ref under `refs/sweatshop/`, see Task 5). Require `cache.Commit(commit) == commit` and that `commit` is an ancestor of (or equal to) a ref under `refs/bundle/<nonce>/` (`for-each-ref --contains <commit> refs/bundle/<nonce>/`). Delete `refs/bundle/<nonce>/*` in cleanup. Tests build bundles the same way: `git update-ref refs/sweatshop/b <commit>` then `git bundle create <f> refs/sweatshop/b ^origin/master`. Then the same tree/checkout/check/sign path as `Attest`.
- **AttestLine**: full-hex check; seed; `commit` must be reachable from `refs/line/heads/*` (`for-each-ref --contains`); then the shared path. This is how the Andon watcher attests master without a bundle.
- Refactor: `Attest` (agentsh's dev path, fetches `sourceDir`) and the two new methods share one `run(ctx, commit, tree, checkout)` that executes checks and signs. `prepare` takes a fetch function.
- **MergeBundle**: like `Merge` but via `AttestBundle`, and pushes the candidate to `w.Upstream`. Factor the push-and-merge tail of `Merge` into a helper used by both.
- **LogRunner**: runs `bash -c command` in `dir` like `ExecRunner`, combined stdout+stderr written to `<Dir>/<id>.log` (dir 0700, file 0600), `id = "ev_" + 16 hex random`; `EvidenceID = id`. Keeps at most the last 4 MiB of output (truncate from the front, prefix `[truncated]\n`). `ContainerRunner{Inner: LogRunner{...}}` is the M1 runner.
